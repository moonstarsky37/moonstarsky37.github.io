OPEN DATA URBAN VIEWER

渋谷を、
まるごと3Dで。

国土交通省 PLATEAU の3D都市モデルを CesiumJS で描画。 渋谷の建物群を、ブラウザだけで自由に見わたせる オープンソースのデモです。

はじめる GitHub で見る

FEATURES

都市を、データで見る。

01

PLATEAU 建築モデル

国土交通省のオープンデータ「PLATEAU」から渋谷区の 3D都市モデルを読み込み、建物群を実寸スケールで再現します。

02

自由なカメラワーク

Cesium のエンジンで、上空からの俯瞰も街路レベルの視点も。 マウスひとつで、シームレスに街を行き来できます。

03

インストール不要

WebGL 対応ブラウザがあれば、その場ですぐ体験。 ビルド成果物は静的ファイルのみで、どこにでも配置できます。

GET STARTED

3ステップで、
手元に渋谷を。

  1. リポジトリを取得 GitHub からソースコードをクローンします。
  2. 依存関係をインストール npm で CesiumJS ほか必要なパッケージを導入。
  3. ローカルで起動 開発サーバーを立ち上げ、ブラウザで開くだけ。
リポジトリへ 
$ git clone https://github.com/moonstarsky37/Shibuya-3D-City-Viewer-Demo.git
$ cd Shibuya-3D-City-Viewer-Demo
$ npm install
$ npm run dev
# 表示されたローカルURLをブラウザで開く
